# Abhiraj Darshankar

Systems craftsman. I learn the underlying mechanics of things — minds, machines, markets, tools, food, materials, organizations — and turn that understanding into useful artifacts.

The trajectory: circuits → cognition → data → reasoning systems. Not a career pivot each time, but the same question asked at different levels of abstraction: *what is actually going on here, and how can that understanding be made usable?*

---

This blog is a public lab notebook. Each post is an attempt to observe something, model the mechanism underneath, and either build an artifact or explain what changed in my thinking.

The goal for any post: you leave with a better model of something.

Posts come in five types: **notes** (short observations), **mechanisms** (how something works underneath), **build logs** (things made), **models** (compressed frameworks), and **interactive** essays (explanations with tools embedded).
